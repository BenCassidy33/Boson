# Boson

Boson is a performant (hopefully) drop-in alternative to Electron.

### Crates

`boson-runtime`: responsible for controlling the program runtimes
(JavaScript and Lua).
`boson-layout`: responsible for determining the layout of the page.
`boson-net`: responsible for networking (HTTP/HTTPS and WebSockets)
`boson-fonts`: responsible for parsing and controlling fonts on the
page.
`boson-window`: responsible for windowing and rendering.
